# Gooo Codegen Experiment: Retry State

This public slice compares ten Gooo-to-Go lowering routes for one explicit intent. It belongs to the 100-case [metaprogramming corpus](https://github.com/kimjooyoon/gooo-metaprogramming-experiments) and keeps its source commit, plan digest, and report digests in [`lineage.json`](lineage.json).

## Plan

재시도 상태를 변환한다. 0은 종료, 1은 2로, 2는 3으로 이동, 음수는 오류 -1, 나머지는 대기 0이다.

- Declared requirements: terminal state, first retry transition, second retry transition, error path, pending fallback
- Reachable rule clauses: 4
- Routes compared: 10
- Declared input domain: 25 integers (`-12` through `12`)
- Average observed behavioral completeness: 94.8%
- Average observed rule-clause completeness: 96.0%
- Laya top-1 route: `boolean_switch`
- Laya seeded sample route: `guard_returns`
- Deterministic fallback route: `guard_returns`

## Reproduce and validate

Run `python3 -m unittest discover -s tests -v` to check case identity, route coverage, score arithmetic, replay digests, report binding, and the exact upstream lineage. The GitHub Actions workflow runs this verifier on pushes and pull requests.

This slice verifies archived evidence; it does not call Laya or regenerate Go code. The canonical corpus contains the runnable matrix harness and compiled-package measurements. Its Laya and deterministic paths are separate experiments. Laya route selection is a decision hint; compiler checks and completeness evidence remain authoritative.

## Limits

Completeness is measured only on this intent's stated requirements and 25-point fixture domain. It does not prove behavior over all integers, unstated user intent, production workflows, or that a Laya-selected route is better. The probability sample is one recorded seeded draw. No model weights are included.
